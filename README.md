# Northbridge University — Admissions Website

Responsive university admissions landing page built with HTML, CSS and vanilla JavaScript.

## Run
1. Extract the ZIP archive.
2. Open `index.html` in a modern browser.
3. No build step or package installation is needed.

## Included
- Programme/course cards with undergraduate/postgraduate filters
- Eligibility guidance section
- Fee details and financial aid information
- Four-step admission process
- Important dates timeline
- Expandable FAQs
- Application enquiry form with basic validation
- Programme dropdown filtered by study level
- Mobile navigation and local SVG illustrations

## Important demo notice
Northbridge University, its programmes, eligibility criteria, tuition amounts, institutional figures and dates are fictional sample content for a website demonstration. Replace these with verified official information before publishing. The form validates in the browser only; it does not upload documents, store entries, or send data to an admissions office. Connect a secure backend and privacy notice before collecting real applicant information.

## Customization
- Edit programme cards and page content in `index.html`.
- Update styles in `styles.css`.
- Update form interactions in `script.js`.
- Replace the editable SVG artwork in `assets/`.
